# Probe: MCP Server Test Suite

A behavioral, safety, and operability test suite + public scorecard for MCP servers. Probe performs dynamic, sandboxed, tool-level behavior testing with evidence and one-command reproduction for every finding, plus self-validation accuracy metrics on injected bugs.

**Status: pre-alpha**

## Development

This project is under active development as part of the Probe initiative to improve MCP server quality and security.

See [ROADMAP.md](ROADMAP.md) for the stages and what "done" means for each.
