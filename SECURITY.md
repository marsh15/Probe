# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in Probe, please report it privately through GitHub: <https://github.com/marsh15/Probe/security/advisories/new>. Include:

- A description of the vulnerability
- Steps to reproduce or proof of concept
- Potential impact
- Suggested fix (if available)

Please do not create public GitHub issues for security vulnerabilities.

## Security Updates

We take security seriously and will address vulnerabilities promptly. Security updates will be released as soon as a fix is available.
